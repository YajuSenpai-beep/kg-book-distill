# 来源与使用边界

## 来源

- 陈华钧《知识图谱导论》，电子工业出版社，2021。
- 刘知远、韩旭、孙茂松《知识图谱与深度学习》，清华大学出版社。

本知识库是对上述两书内容的**转述、结构化与工程化整理**，用于学习、检索与方案设计。它不是原书的替代品，也不包含可直接替代原书阅读的章节全文。

## 不包含

- 原书 PDF、逐字抽取文本、长段原文。
- 图表扫描页（`figures/pages/`）、模型缓存、向量缓存。
- 原书下载来源与第三方站点信息。
- API key、账号凭证、个人绝对路径。

## 使用边界

- 个人学习、研究、技术方案设计可用。
- 不要把本库当作原书的授权副本再分发。
- 商业再分发、出版或打包销售前，应自行取得权利人授权；本仓库不授予知识内容的再许可。
- 公式、页码、OCR 细节可能存在误差；关键结论请对照原书。
- 如权利人认为某部分内容不宜公开，请联系维护者，我们会核实并下架相关内容。

## 生成链

```text
PDF → 文本层抽取 / 本地 OCR → 人工转述为知识点 → 校验 → Obsidian / Anki / BM25
```

`build_kb.py`、`build_exports.py`、`tests/` 可复现上述结构。原始 PDF 与逐字抽取文本不随本库分发。
