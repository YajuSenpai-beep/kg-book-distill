# 稀疏矩阵采样策略

> B-06-03-08 · 书B 第6章 语言知识的自动获取 · 6.3 基于协同过滤和矩阵分解的义原预测

> 本节图表：表6-1 模型对义原预测的结果、表6-2 列出了SPWE+SPSE 集成模型为、表6-3 不同词性下义原预测结果、表6-4 不同词频下义原预测结果（[[40-图表索引]]）

## 定义

词-义原矩阵极稀疏；对 0 元素低概率采样、非 0 元素全采样，避免 0 主导训练。

## 关键要点

- 0 元素以 0.5% 概率采样
- 非 0 元素全采样
- 聚焦词-义原对
- 提升矩阵分解效果
