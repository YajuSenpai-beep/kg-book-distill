# 盲测自动评分（仅概念覆盖）

| ID | 命中 | 缺失 | 结论 |
|---|---:|---|---|
| D01 | 3/3 | — | 不适合直接上 GNN：平均度 < 2 属高度稀疏，应先用 KRL/规则/外部信息，GNN 只做辅助。 |
| D02 | 3/3 | — | 不要用 TransE 硬扛：一对多/多对多明显时选 TransR 或 KR-EAR，必要时用 CTransR。 |
| D03 | 3/3 | — | 先分块、再块内匹配，避免两个百万级本体的全量 O(M×N) 笛卡尔积比较。 |
| D04 | 3/3 | — | 不能只用嵌入模型给结论；高风险推理必须混合符号/规则、输出证据链并人工复核。 |
| D05 | 3/3 | — | 必须降噪，不能直接拿远程监督标注训练；用多实例 bag 聚合与注意力等四类手段。 |
| D06 | 3/3 | — | 用融合外部信息的 KRL：DKRL（描述）/TKRL（类型）/IKRL（图像），或用 MetaR 元学习；需泛化到新节点则用 GraphSAGE/GAT 类归纳模型。 |
| D07 | 3/3 | — | 嵌入模型不够时改用多跳逻辑查询方法：BetaE（逻辑操作映射为概率分布变换）、强化学习游走（MINERVA）或查询分解。 |
| D08 | 2/3 | 免索引邻接 | 不默认上图数据库：只有以 2+ 跳路径/子图匹配为主且规模需要时才用原生图库，简单点查与聚合优先现有关系库。 |
| D09 | 3/3 | — | 按顺序判断：需要标准交换/跨组织语义互操作 → RDF；需要类公理/基数/传递互反/函数关系 → OWL 子语言；否则默认属性图 + 轻量 Schema。 |
| D10 | 3/3 | — | 没有对齐种子时先做分块 + 规则/字符串/结构对齐，再用无监督联合嵌入迭代；不要全量比较。 |
| D11 | 3/3 | — | 选“问句模板 + 类型检查”，保证高准确与低延迟；生产系统可加混合兜底。 |
| D12 | 2/2 | — | 开放域问题多、图谱较大时选检索排序（实体链接 → 候选路径/实体 → 排序）；复杂组合问题再叠加语义解析。 |
| D13 | 3/3 | — | 知识注入语言预训练模型有三种做法：实体向量注入、预训练任务注入、外部适配器；另可用检索增强与图谱预训练服务。 |
| D14 | 3/3 | — | 不默认做多模态知识图谱；只有图像/视频对目标任务有可测增益、且覆盖率与实体对齐可行时才做。 |
| D15 | 3/3 | — | 单组织内部不建议上区块链/联邦知识图谱；集中式平台足够，除非存在多参与方协作与确权/溯源的真实需求。 |
| D16 | 3/3 | — | 低频/未登录词优先用字信息增强（CSP 系列），不要只用词向量协同过滤。 |
| D17 | 3/3 | — | 目标语言没有义原标注时用跨语言迁移 CLSP：源语言义原标注 + 跨语言词对齐，把知识迁移过去。 |
| D18 | 3/3 | — | 事件抽取应先定义事件 Schema（事件类型、触发词、论元角色、必填论元），再按触发词分类 → 论元检测 → 论元角色分类推进。 |
| D19 | 3/3 | — | 必须报 filtered 的 MR/MRR/Hit@1/3/10 并注明 raw/filtered，同时按关系基数与头/尾频次切片；只报未过滤指标不可比。 |
| D20 | 3/3 | — | 不要先换更大模型：先做分层错误分析与标签体系/领域漂移诊断，不达标先降 Schema 范围。 |
