# Skill 多模型盲测报告

日期：2026-11-22
对象：`kg-engineering` Skill（测试时为修改前版本）
用例：20 条，`backtest-questions.jsonl`（不含期望答案）
运行：4 个独立 Agent，模型分别为 Default（会话默认）、Haiku、Sonnet、Opus

## 方法

1. 每个 Agent 不带主会话上下文，只允许读 `SKILL.md` 与 `references/`。
2. 明确禁止读取 `decision-cases.jsonl`、`backtest-report.md`、`evals/README.md`。
3. 输出统一为 `id / decision / actions / evidence / confidence`。
4. 用 `grade_backtest.py` 统计 expected 概念覆盖；分支正确性由主会话逐题复核。
5. 评分只看“是否命中关键概念”，同义表达按脚本中的 `SYNONYMS` 归一；不要求逐字一致。

结论先行：

- **决策分支 80/80 全对**，没有一条答反方向。
- 差异全部出在“具体方法名/机制解释”的召回，不在“选哪条路”。
- 最弱模型 Haiku 的覆盖率 89.8%，仍能选对全部 20 个分支；强模型的主要缺口是 D16/D17 的方法名。

## 稳定性分析

### 1. D08：所有模型都选对，但多数不说“免索引邻接”

- Haiku/Sonnet/Default 都答“2+ 跳才上图库”，但只有 Opus 明确写出“免索引邻接”。
- 说明**分支规则稳定，理由链不稳定**。选型表里有这四个字，但输出要求没有强制写理由。
- 这不是模型能力问题，是 Skill 的提示设计问题：应把“选原生图库必须解释免索引邻接与遍历复杂度”变成 Stage 2 的交付要求，而不是只放在检查清单。

### 2. D16/D17：强模型反而漏掉 CSP/CLSP

- Sonnet/Opus 都答“字信息 + 协同过滤/矩阵分解”“跨语言对齐 + 种子词典”，方向正确，但没点名 CSP/CLSP。
- Haiku 反而命中了 CSP/CLSP，说明它读了 `language-kg.md`；Sonnet/Opus 只读了 `SKILL.md` 的 M10 摘要。
- 这暴露了路由问题：**M10 摘要没有把 CSP/CLSP 写进去，模型就可能停在摘要层**。

### 3. Haiku 的四处细节缺口

| 题 | 缺什么 | 性质 |
|---|---|---|
| D05 | 多实例 bag、注意力 | 只答“要降噪”，没答主流降噪手段 |
| D07 | BetaE | 答了查询分解/路径/强化学习，漏了逻辑查询嵌入 |
| D09 | W3C | 答了 RDF/OWL 的条件，没点标准组织 |
| D12 | 实体链接 | 选了检索排序，但漏了检索排序的前置步骤 |

这些都是“方法召回”缺口，不是“决策方向”错误。

### 4. D09 的 W3C 缺失是跨模型问题

Haiku 和 Opus 都没写 W3C；Sonnet 在动作里写了。`SKILL.md` 表示选型表已有“W3C 标准”，但只有部分模型复述。属于低风险表述问题。

## 已做的 Skill 修改

以下修改在**本轮测试之后**加入，尚未复测：

1. Stage 2 输出要求：选原生图库必须写明“免索引邻接 + 遍历复杂度”的依据（对应 D08）。
2. Stage 5 多跳行加入 `BetaE`（对应 D07）。
3. Stage 6 明确“无论选哪种 KGQA，先做实体链接与类型检查”（对应 D12）。
4. M3 步骤改为“远程监督/弱监督 → 多实例 bag + 注意力降噪”（对应 D05）。
5. M10 步骤改为“字信息 CSP/跨语言 CLSP”（对应 D16/D17）。

另外，检查清单中本来就有“若选原生图库，是否能解释免索引邻接与遍历复杂度？”，但 3 个模型仍没在答案里体现。这说明**检查清单不等于输出约束**，所以第 1 条改到了 Stage 2 的交付物要求里。

## 这个报告能证明什么

- 4 个不同模型在只看 Skill 的条件下，80 个决策全部分支正确。
- 概念覆盖率 89.8%–98.3%，说明 Skill 的方法细节对弱模型也有基本支撑。
- 波动点集中在具体方法名和机制解释，可用于定向改 Skill。

## 不能证明什么

- **每个模型只跑 1 次**，没有温度/采样重复，不能给出置信区间。
- **模型版本未锁定**：Haiku/Sonnet/Opus 的具体版本由运行环境决定，换版本结果可能变化。
- **评分含同义归一**：`SYNONYMS` 由主会话定义，可能放宽或收紧某些词。
- **20 条是合成用例**，不等于真实项目分布，也不覆盖多轮澄清、预算约束、组织政治。
- **分支正确由主会话复核**，不是独立人类专家盲评。

## 回归验证（修改后）

用修改后的 Skill 让 Haiku 重答 7 道弱项题（D05/D07/D08/D09/D12/D16/D17），其余条件不变：

| 题 | 修改前 | 修改后 | 变化 |
|---|---:|---:|---|
| D05 | 1/3 | 3/3 | 补齐多实例 bag + 注意力 |
| D07 | 2/3 | 3/3 | 补齐 BetaE |
| D08 | 2/3 | 3/3 | 补齐免索引邻接 |
| D09 | 2/3 | 2/3 | 仍缺 W3C |
| D12 | 1/2 | 2/2 | 补齐实体链接 |
| D16 | 3/3 | 3/3 | 保持 |
| D17 | 3/3 | 3/3 | 保持 |
| **合计** | **14/20（70%）** | **19/20（95%）** | **+5** |
| 全命中题数 | 2/7 | 6/7 | +4 |

结论：5 处修改中有 4 处直接生效（D05/D07/D08/D12），D16/D17 维持满分；D09 的 W3C 仍未被复述，但分支一直正确，属于低风险表述遗漏。

注意：这是**针对弱项题的单模型回归**，不是完整 20 题复测，存在针对性过拟合的可能；下一轮应跑完整 20 题并重复 3 次。
