# 语言知识图谱（Lexical / Sememe KG）

补充模块，对应原书“语言知识图谱”部分（HowNet/义原）。用于回答：**什么时候需要词义级知识图谱，以及怎么建、怎么用、怎么评。**

---

## 1. 适用边界

适合：
- 需要词义消歧、词相似度、义项级语义表示。
- 低资源/低频词需要外部语义知识增强。
- 需要可解释的词义分解（义原组合）。
- 词典扩展、文本分类、语言模型的知识增强。
- 构建面向中文/多语言的语义知识库。

不适合：
- 通用实体关系图谱（人物、公司、产品）——用世界知识图谱。
- 只需要词向量、不关心义项与语义分解。
- 没有语言学标注能力，且无法接受自动预测噪声。
- 任务对时效性要求极高、词义变化快且无更新机制。

与 WordNet 的区别：
- WordNet 以同义词集（synset）组织词义，强调词与词的语义关系。
- HowNet 以义原（sememe）为最小语义单位，强调词义可分解为义原组合；标注是义项级的。

---

## 2. 核心概念

| 概念 | 含义 | 工程用途 |
|---|---|---|
| 词 word | 语言单位 | 词典条目 |
| 义项 sense | 词的一个含义 | 多义词的不同语义 |
| 义原 sememe | 最小语义单位 | 词义分解的原子 |
| 义原集合 | 一个义项由若干义原标注 | 语义表示 |
| 义原关系 | 义原之间的层次/依存关系 | 语义组合与推理 |
| 词-义原矩阵 | 词与义原的标注共现 | 预测与嵌入 |
| 义原嵌入 | 义原的向量表示 | 语义相似度 |
| 义项嵌入 | 义项向量（常由义原聚合） | 词义消歧 |
| 词嵌入 | 词向量（可由义项/义原聚合） | 下游任务 |

关键假设：
- 词义可以由有限义原集合组合表示。
- 相似词倾向共享义原；相似义原有相似上下文。
- 多义词的不同义项有不同义原标注。

---

## 3. 表示学习路线

### 3.1 义原向量

| 模型 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| 义项不敏感 | 合并词的所有义项义原，用平均义原向量预测词向量 | 简单 | 忽略多义 |
| 义项敏感 | 根据上下文选择最接近的义项，只用该义项义原预测 | 处理多义 | 依赖上下文质量 |

训练要点：
- 可先在大规模语料上训练词向量，再固定词向量、学习义原向量。
- 目标：义原组合能预测对应词；可用层次 Softmax/负采样加速。
- 义项选择可用上下文平均向量与义项向量的余弦相似度。

### 3.2 义原编码的词表示（SE-WRL）

| 模型 | 词向量来源 | 上下文处理 | 适用 |
|---|---|---|---|
| SSA（简单义原聚合） | 所有义原向量平均 | 不区分义项 | 基线、简单场景 |
| SAC（义原上下文注意力） | 目标词用原词向量；上下文词用义原注意力 | 对上下文词做软词义消歧 | 上下文歧义明显 |
| SAT（义原目标词注意力） | 上下文词用原词向量；目标词用义原注意力 | 用多个上下文词选择目标词义项 | 目标词多义 |

工程建议：先跑 SSA 基线；多义词是主要误差来源时上 SAC/SAT。

## 4. 义原自动标注（预测）

### 4.1 三条技术路线

| 路线 | 代表 | 信息源 | 适用 |
|---|---|---|---|
| 协同过滤 | SPWE | 相似词的义原标注 | 有可靠词向量、词-义原矩阵可信 |
| 矩阵分解 | SPSE/SPASE | 词-义原 + 义原-义原共现 | 需要义原间关系 |
| 字信息增强 | SPWCF/SPCSE/CSP | 词内部字信息 | 中文、低频词、未登录词 |
| 跨语言迁移 | CLSP | 源语言标注 + 跨语言对齐 | 目标语言无义原标注 |

### 4.2 SPWE（词嵌入协同过滤）

- 对词 w 的义原 s 打分：相似词的义原标注加权求和。
- 权重 = 词向量余弦相似度 × 是否标注 × 相似度排名置信因子。
- 只让最相似的若干词产生强影响，避免不相关词噪声。
- 适合高频词；低频词词向量不可靠时效果下降。

### 4.3 SPSE / SPASE（矩阵分解）

- 同时分解词-义原矩阵与义原-义原矩阵（PMI）。
- 把词与义原映射到同一低维空间，用余弦相似度预测。
- 词-义原矩阵极稀疏：对 0 元素低概率采样，对非 0 元素全采样。
- SPASE 假设词向量 = 义原向量加权和；参数少，复杂组合表达受限。

### 4.4 CSP（字信息增强）

- **SPWCF**：按字在词中的位置（首/中/尾）找相似词，推荐义原。
- **SPCSE**：用字嵌入 + 义原嵌入做矩阵分解；一个字可有多个嵌入，选与义原最接近的。
- **组合**：高频词用“内部 + 外部”模型；低频词只用内部模型，避免不可靠词向量带来噪声。
- 适用：中文新词、低频词、未登录词。

### 4.5 CLSP（跨语言）

三部分：
1. 单语词表示：源/目标语言分别用 Skip-gram。
2. 跨语言对齐：种子词典 + 匹配机制（Viterbi EM，空词阈值过滤）。
3. 基于义原的词表示：同义词正则或义原嵌入正则。

用途：把有义原标注的源语言知识迁移到无标注的目标语言。

### 4.6 预测流程

```text
词表 + 义原标注（源）
→ 词向量/字向量
→ 候选义原打分（协同过滤/矩阵分解/字信息/跨语言）
→ 阈值与 top-k
→ 人工抽检
→ 回补标注
```

质量控制：
- 分高频/低频/未登录词报告。
- 分义原类型报告（具体义原 vs 抽象义原）。
- 人工抽检 100–300 词，统计 precision/recall/F1。
- 预测结果不能直接当人工标注；需置信度与复核。

## 5. 应用

### 5.1 词典扩展（以 LIWC 为例）

- 任务：给词打层次标签（粗到细），扩展人工词典。
- 方法：层次解码器（seq2seq，按标签树路径逐层预测）+ 义原注意力（不同义原对不同标签权重不同）。
- 解码：beam search；用阈值筛选标签序列。
- 价值：处理多义与类别难区分；比平铺分类更符合标签层次。
- 评估：Micro-F1、按类别加权 F1；分层报告。

### 5.2 义原驱动的神经语言模型（SDLM）

三部分：
1. **义原预测器**：由上下文预测每个义原的权重（Sigmoid）。
2. **义项预测器**：把每个义原视为“专家”，对相关义项打分；专家积组合。
3. **词预测器**：词的概率 = 其义项概率之和。

工程要点：
- 义原数约 2000，参数量大；用基底矩阵共享参数。
- 输出层可与输入词嵌入权重绑定。
- 可解释性：能看出哪些义原被激活，支持未登录词的语义解释。
- 评估：困惑度、下游任务（标题生成等）。

### 5.3 其他应用

| 应用 | 用法 |
|---|---|
| 词相似度 | 义原/义项向量余弦 |
| 词义消歧 | 上下文选择义项 |
| 情感分析 | 义原作为情感特征 |
| 文本分类 | 义原增强词表示 |
| 低资源 NLP | 义原知识迁移 |
| 词典构建 | 义原预测 + 人工审核 |

## 6. 选型决策

```
是否已有可用的词义知识库？
├─ 是（WordNet/HowNet/自有词典）→ 直接用，评估覆盖与语言匹配
└─ 否 → 是否需要义项级/语义分解？
         ├─ 否 → 词向量/同义词词典即可
         └─ 是 → 是否有语言学标注能力？
                  ├─ 是 → 人工标注 + 自动预测辅助
                  └─ 否 → 自动预测 + 人工抽检；接受噪声
                           ↓
                  是否中文/低频词多？
                  ├─ 是 → 加入字信息（CSP）
                  └─ 否 → 词嵌入协同过滤/矩阵分解
                           ↓
                  是否多语言？
                  ├─ 是 → 跨语言对齐（CLSP）
                  └─ 否 → 单语预测
```

---

## 7. 评测

| 任务 | 指标 | 注意 |
|---|---|---|
| 义原预测 | Precision/Recall/F1 | 分高频/低频/未登录；top-k |
| 词相似度 | Spearman/Pearson | 与人工相似度基准比 |
| 词义消歧 | Accuracy/F1 | 分词性、多义程度 |
| 词典扩展 | Micro-F1/加权 F1 | 分层报告 |
| 语言模型 | Perplexity | 与同规模基线比 |
| 下游任务 | 任务指标 | 必须报告增益与成本 |

---

## 8. 反模式

1. 把义原预测结果直接当人工标注使用。
2. 忽略多义词，所有义项混在一起训练。
3. 低频词只用词向量，不用字信息。
4. 跨语言直接机器翻译词典，不做语义对齐。
5. 只报整体 F1，不报低频/未登录词。
6. 义原数量大却不做参数共享，导致过拟合。
7. 把语言知识图谱当世界知识图谱用（实体关系建模）。
8. 没有语言学专家参与，闭门造义原体系。

- [ ] 定义义原集合、义项粒度、标注规范。
- [ ] 先做小规模人工标注，再自动预测扩展。
- [ ] 分高频/低频/未登录词评估。
- [ ] 预测结果经人工抽检后回补。
- [ ] 下游任务验证增益，不只看义原预测指标。
