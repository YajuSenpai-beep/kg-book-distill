# 评估数据集与口径

补充模块。用于回答“用什么数据评、指标怎么报、公开集能不能替代领域验收”。

---

## 1. 知识图谱补全 / 链接预测

| 数据集 | 领域 | 特点 | 常用任务 |
|---|---|---|---|
| WN18 / WN18RR | 语言知识 | 关系类型少、结构规律；WN18RR 去除了逆关系泄漏 | 链接预测 |
| FB15K / FB15K-237 | 通用世界知识 | 关系类型多；FB15K-237 去除了训练/测试逆关系泄漏 | 链接预测 |
| FB24K | 通用 + 属性 | 含属性三元组，适合属性/关系联合预测 | 实体/关系/属性预测 |
| YAGO / DBpedia 子集 | 通用/多语言 | 规模大、噪声与不完整度不同 | 链接预测、实体分类 |
| 领域自建集 | 医疗/金融/工业 | 最贴近业务，但规模小、标注贵 | 领域验收 |

**指标**：MR、MRR、Hit@1/3/10；必须注明 raw/filtered；按 1-1/1-N/N-1/N-N 与头/尾频次切片。

**常见坑**：
- 不做 filtered：其他真实三元组被当成负例，指标不可比。
- 随机切分导致逆关系泄漏：FB15K/WN18 的经典问题，优先用 FB15K-237/WN18RR。
- 只报总体：长尾关系可能接近随机。

## 2. 关系抽取

| 数据集 | 语言/领域 | 特点 | 用途 |
|---|---|---|---|
| NYT | 英文新闻 | 远程监督常用，实体链接到 Freebase | bag 级关系抽取 |
| SemEval 关系数据 | 英文 | 人工标注、关系类型有限 | 有监督基线 |
| ACE / FrameNet | 英文 | 事件/框架标注 | 事件抽取、弱监督 |
| DuEE | 中文 | 百度中文事件抽取数据集 | 中文事件抽取 |
| 领域标注集 | 各领域 | 关系 Schema 自定义 | 领域验收 |

**指标**：句级与 bag 级 P/R/F1；按关系类型、频次、来源分层；远程监督要报降噪前后对比。

## 3. 知识图谱问答

| 数据集 | 领域 | 特点 | 用途 |
|---|---|---|---|
| QALD | 多领域/多语言 | 多语种、跨数据集、混合问答 | 语义解析/检索 |
| WebQuestions | 通用（Freebase） | 6k+ 问答对，单实体为主 | 开放域问答 |
| SimpleQuestions | 通用 | 单三元组事实 | 简单问答基线 |
| MetaQA | 电影 | 1/2/3 跳样本约 1:1:1 | 多跳问答 |
| ComplexQuestions | 通用 | 复杂/组合问题 | 组合推理 |
| WikiMovies | 电影 | 领域问答 | 领域基线 |

**指标**：答案准确率（exact/语义等价）、覆盖率、P50/P95 延迟、可解释率、人工接管率。

**常见坑**：公开集分数不能替代领域验收；领域评估集必须来自真实查询日志。

## 4. 语言知识图谱（HowNet/义原）

| 资源 | 用途 | 备注 |
|---|---|---|
| HowNet | 义原标注、义项级词义 | 约 2000 义原、十万级词条 |
| SogouT | 词/字嵌入训练 | 大规模中文语料 |
| LIWC 中文词典 | 词典扩展 | 标签层次、类别不平衡 |
| LCSTS | 标题生成 | 语言模型下游评估 |
| 人民日报语料 | 语言模型困惑度 | 中文新闻文本 |

**指标**：义原预测 P/R/F1、top-k 命中；词相似度 Spearman；WSD 准确率/F1；语言模型困惑度。

**常见坑**：只报整体 F1，不报低频/未登录词；预测结果直接当人工标注。

## 5. 图算法 / GNN

| 数据集 | 任务 | 备注 |
|---|---|---|
| Cora/Citeseer/Pubmed | 节点分类 | 引文网络，直推设定常用 |
| OGB 系列 | 节点/链接/图分类 | 大规模、标准化切分 |
| 自建 KG 子图 | 实体分类/链接预测 | 需报告结构统计 |

**指标**：Accuracy/F1、AUC/AP、Hit@n；直推/归纳分开；时间切分防泄漏。

---

## 6. 公开集 vs 领域验收

| 目的 | 用什么 |
|---|---|
| 证明方法可实现 | 公开集 + 标准指标 |
| 证明对业务有用 | 领域评估集 + 业务指标 + 基线 |
| 上线前 | 小流量 A/B + 人工接管率 + 延迟 |

原则：公开集只回答“方法是否 work”，领域集才回答“项目是否 work”。

## 7. 评估协议检查清单

- [ ] 切分方式：随机 / 时间 / 实体级？是否泄漏？
- [ ] 链接预测：raw/filtered 是否注明？是否按关系基数切片？
- [ ] 抽取：句级/bag 级是否都报？是否分关系/频次？
- [ ] QA：是否覆盖全部能力问题？是否报拒答/接管？
- [ ] 公开集与领域集是否分开报告？
- [ ] 是否报告基线、成本、延迟？
